# TESTING — 三轮测试、精度与覆盖率证据

本工程要求：**至少 3 轮测试通过后才提交；用例覆盖主要分支；解析精度误差 < 5%**。以下为实测记录。

## 第 1 轮：功能与契约（59 项）

| 套件 | 数量 | 内容 |
| :--- | ---: | :--- |
| `frontmatter.test.mjs` | 11 | 捆绑 SKILL.md 解析、块标量、CRLF、非法名、超限、元数据、provider 契约、abort |
| `safety.test.mjs` | 9 | 畸形 YAML、flow 集合、字节炸弹、未闭合、空描述、非法候选、取消边界 |
| `golden.test.mjs` | 39 | 标量/引号/注释/块标量/嵌套元数据/标志位/编码/BOM/重复键/保留键/错误分支 |

结果：**59 通过 / 0 失败**。

本轮收益：发现并修复真实缺陷——制表符缩进检测写成 `trimStart().startsWith('\t')`，`trimStart()` 会先移除 tab，导致缩进检查永不触发；已改为对原始行做 `/^[ ]*\t/` 匹配。

## 第 2 轮：差分精度（300 例）

- 种子化（seed=20261025）生成器构造合法 frontmatter，期望值由构造过程直接保证；
- 覆盖 plain / single / double / literal / folded 五种描述写法，元数据 0~2 层嵌套，随机标志位组合；
- 指标：`error_rate = 失配用例 / 300`，门限 **< 5%**。

实测：**300 例 / 0 失配 / 误差率 0.00%**，解析耗时 3.2 ms。

稳定性：同一语料连续两次运行，结果逐字节一致。

交叉对比：`yaml` 库与内置兜底解析器的差分对比在本机跳过（本地未安装 `yaml`，两侧走同一路径无意义）；在任何可解析 `yaml` 的环境中该用例自动启用，门限同样 < 5%。

## 第 3 轮：健壮性与全量回归（77 项 × 3 次）

健壮性套件 15 项：原型污染（`__proto__` 保留键）、YAML 锚点/别名字符串降级、25 路并发一致、重复调用确定性、50 技能大目录排序、无 SKILL.md 目录容错、符号链接技能目录、非法技能按文件路径报错、超过 1 MiB 拒绝、静态安全不变量（无网络/无子进程/无 `eval`/无 HTTP URL）、无安装期脚本。

全量回归连续 3 次，每次结果一致：**77 项 / 76 通过 / 0 失败 / 1 跳过**（跳过项为 yaml 交叉对比）。

覆盖率（单进程全量）：**行 95.98% / 分支 89.56% / 函数 98.54%**。

官方静态审计：**80/80，0 硬阻断**（`isolated-acceptance-ready`）。

## 测试边界

- 测试仅写入系统临时目录（`os.tmpdir()`），结束即清理，**不触碰真实 `~/.dsh`**；
- 不联网、不安装依赖、不调用安装命令；
- 运行时验收（E3/E4，一次性 Profile 安装与真实 Profile 冒烟）不在本文件范围内，见 `docs/MARKETPLACE.md`。
